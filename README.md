A multi-functional Python program that combines a calculator with an interactive math game.

## ✨ Features

- **Simple Calculator**: Addition, subtraction, multiplication, division, and power
- **Scientific Calculator**: Sin, cos, tan, cot, logarithm, factorial, and BMI calculator
- **Math Game**: Three difficulty levels with dynamic scoring system
- **Persistent Storage**: Scores and settings saved between sessions (JSON)
- **History Tracking**: All calculations logged automatically (CSV)
==========================================================================

## 🎮 Game Levels

**Easy:** Addition and subtraction with numbers 1 to 100.

**Medium:** Addition, subtraction, and multiplication with numbers 100 to 200 (for + and -) or 5 to 15 (for *).

**Hard:** Addition, subtraction, multiplication, and division with numbers 100 to 300 (for + and -) or 5 to 20 (for * and /).

==========================================================================

## 📁 Files Created by the Program

**history.csv**  
Simple calculator history.

**advanced_history.csv**  
Scientific calculator history.

**score.csv**  
Game history with answers.

**score.json**  
Game settings (level, score, threshold).
